# Learn JavaScript

Kumpulan kode latihan pembelajaran JavaScript yang dipisahkan dari repositori `mayyaisbetter/learn-frontend`.

## Struktur Materi

- `belajar-javascript-dasar/` - Variabel, tipe data, operator, percabangan, perulangan, fungsi, scope, closure, destructuring, dan strict mode.
- `belajar-javascript-standard-library/` - Built-in object dan utilitas standar seperti Array, String, Number, Date, Math, JSON, Map, Set, RegExp, Proxy, dan Reflect.
- `belajar-js-object-oriented-programming/` - Constructor function, prototype, inheritance, class, field/method publik dan privat, static, error handling, dan iterable.
- `belajar-js-modules/` - JavaScript Modules (import, export, default, named, aggregate, dan dynamic module).
- `belajar-js-DOM/` - Document Object Model, selector, manipulasi element/node/attribute, event handling, dan form.
- `belajar-js-asynchronous/` - Timer, AJAX, Promise, Fetch API, Async/Await, dan Web Worker.
- `studi-kasus-js-todolist/` - Studi kasus aplikasi Todo List menggunakan JavaScript.

## Cara Menjalankan

Buka berkas `.html` melalui local web server (misalnya Live Server atau `npx serve`), khususnya untuk materi `belajar-js-modules/` dan `belajar-js-asynchronous/` yang memerlukan protokol HTTP.
